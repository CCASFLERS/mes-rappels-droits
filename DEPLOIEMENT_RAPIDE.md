# Déploiement gratuit rapide

## 1. Déposer le projet sur GitHub

Créer un dépôt nommé `mes-rappels-droits`, puis envoyer tout le contenu de ce dossier.

## 2. Déployer avec Vercel

- Aller sur Vercel
- Add New Project
- Importer le dépôt GitHub
- Cliquer Deploy

Vercel détecte Vite automatiquement. Si besoin :

- Build command : `npm run build`
- Output directory : `dist`

## 3. Utiliser le QR code

Quand le site est en ligne :

1. Ouvrir l'adresse Vercel
2. Aller dans Réglages
3. Le QR code est généré automatiquement
4. L'imprimer ou le montrer aux personnes

## 4. Installation

Le QR code ne passe pas par un store : il ouvre la PWA. La personne peut ensuite l'ajouter à son écran d'accueil.
